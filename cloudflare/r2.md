# R2 — `nova-country-flags` (private)

- 257 country flags stored as `<CC>.svg` (e.g. `SG.svg`), uploaded with `scripts/upload-flags.sh`.
- The bucket has **no public access** (r2.dev disabled, no custom domain). The only way to read an object is the
  Worker's R2 binding (`env.FLAGS`).
- `GET https://tunnel.strikemap.space/secure/SG` → Access → Worker → `env.FLAGS.get("SG.svg")` → `image/svg+xml`.
